# Smart Deals Server

Backend server for the Smart Deals application.

Built with Node.js, Express.js, MongoDB, and Firebase Authentication.

## Features

- User Authentication
- Product Management
- Bidding System
- Protected APIs
- MongoDB Database
- Firebase Authentication

## Technologies

- Node.js
- Express.js
- MongoDB
- Firebase
- JWT

## API

- `/users`
- `/products`
- `/bids`

## Frontend

React + Vite
